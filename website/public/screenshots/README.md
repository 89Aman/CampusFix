# Screenshot Instructions

Please save your app screenshots to this folder with these names:

1. **issues.png** - Campus Issues list screen (the one showing "Water cooler leaking near gym")
2. **admin.png** - Admin Dashboard screen (the one showing "Manage Issues")
3. **report.png** - Confidential Report form screen
4. **safety-tools.png** - Safety Tools screen (with SOS button)
5. **community.png** - Safety Community screen (showing critical alerts)

## File naming:
- `issues.png` → Campus Issues feed
- `admin.png` → Admin Dashboard 
- `report.png` → Confidential Report
- `safety-tools.png` → Safety Tools / SOS
- `community.png` → Safety Community

After saving these files, refresh the website at http://localhost:3000 to see them displayed.
